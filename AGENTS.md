# Agent Skills & Plugins Repository Guide (`AGENTS.md`)

This repository packages reusable multi-harness AI coding skills and plugins across **Google Antigravity (`agy`)**, **Claude Code (`claude`)**, and **OpenAI Codex CLI (`codex`)**:

- **`plugins/ast-graph`**: The canonical multi-repo AST & Cross-Layer Lineage GraphDB plugin. It includes a stdio MCP server (`ast-graph`), `SessionStart`/`PostToolUse` lifecycle hooks, rules (`rules/AGENTS.md`) and the `ast-graph-traceability` skill (`skills/ast-graph-traceability/SKILL.md`). `plugins/ast-graph-traceability` is a deprecated stub; do not add code there.
- **`plugins/feature-flags`**: Reference plugin demonstrating runtime feature flags via lifecycle hooks (`SessionStart`, `PreInvocation` ephemeral context injection, and `PreToolUse` tool gating/argument rewriting) backed by a 4-tier workspace/global flag hierarchy and CLI (`scripts/flags-cli.mjs`).
- **`plugins/thinking-arcade`**: Session-gated Space Invaders sidecar game (**Model Invaders**) that only renders and unpauses while the agent is actively thinking or executing tools (`PreInvocation`/`UserPromptSubmit` + `PreToolUse` -> `Stop` with `fullyIdle` check), with a single cross-session game window, a "Needs you" list (`conversation://` links in the side pane), Keep playing ack, and close detection, backed by a managed sidecar server (`sidecars/arcade-daemon/sidecar.json` on `127.0.0.1:4777`) and cross-marketplace configs for Antigravity, Claude Code, and OpenAI Codex CLI.
- **`plugins/adaptive-learning`**: Mastery-based interactive learning journeys (`agentic-ui-architectures`, `token-economics-and-ast-graph`, `cloud-run-l4-and-vertex-inference`) that embed `<agent-embed>` micro-widgets, `diff` blocks, fenced code blocks, and Mermaid diagrams directly inside `ask_question`, validate answers via `scripts/journey-engine.mjs`, and pivot to alternative teaching modalities when a learner misses a concept.
- **`.skills/*`**: Standalone skills (`apple_container`, `gcp_auth`, `llm_tutor`, `session-journal`, `update_documentation`).
- **`.claude-plugin/marketplace.json`**: Claude Code plugin marketplace manifest (`claude plugin marketplace add davenportjw/agent-skills`).
- **`.agents/plugins.json` & `.agents/skills.json`**: Google Antigravity discovery manifests.
