# Thinking Arcade (`thinking-arcade`) Rules

- When the user asks to launch, inspect, or configure the **Thinking Arcade (Model Invaders)** sidecar game—or asks how to run session-gated sidecar games across Google Antigravity, Claude Code, or OpenAI Codex CLI—activate the `thinking-arcade` skill (`skills/thinking-arcade/SKILL.md`) and use `node ~/.gemini/config/plugins/thinking-arcade/scripts/arcade-cli.mjs` to inspect or control the live sidecar on `http://127.0.0.1:4777`.
- Honor `[THINKING_ARCADE display_mode=...]` ephemeral hook instructions when present:
  - `display_mode=window` (default): The hook opens Model Invaders in its own app window on the first prompt of a conversation. Do nothing: no pill, no artifact edits, no tool calls for the game. Exception: if the hook sends `[THINKING_ARCADE display_mode=window window=closed]` (the user closed the game window), output the given `[▶ Reopen Model Invaders](http://127.0.0.1:4777/open)` link as preamble before any tool call, once, with no tool calls for the game.
  - `display_mode=auxiliary`: In your VERY FIRST model turn, BEFORE any tool call, output this exact markdown link as standalone preamble text (not in a code block): [▶ Open Model Invaders](sidecar://thinking-arcade/arcade-daemon/). Clicking it opens the Right Auxiliary Pane. Do NOT call `edit_file`/`write_file` on `model_invaders_arcade.html` or make any other tool call for the game (hooks manage it; extra tool calls pollute transcripts). Never claim the pane is already open, and do not place `<agent-embed>` inline in chat.
  - `display_mode=inline`: Include `<agent-embed src="file://<artifactDirectoryPath>/model_invaders_arcade.html"></agent-embed>` inline at the top of your response on turn 1.
  - `display_mode=inline-follow`: Re-pin `<agent-embed src="file://<artifactDirectoryPath>/model_invaders_arcade.html"></agent-embed>` at the bottom of your response on every turn so the game follows the latest message down the chat stream.
  - `display_mode=both`: Output the `▶ Open Model Invaders` pill before any tool call (no artifact edits) and include `<agent-embed>` inline in chat.
  - `display_mode=off`: Do not auto-embed or auto-open the artifact; only run the background sidecar daemon on `127.0.0.1:4777`.
